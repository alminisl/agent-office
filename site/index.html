Agent Office turns every Claude Code session into a pixel-art employee with a desk, a status and a personality. See at a glance who's working, who's waiting for you and what everyone did today, and jump back into any session with one click.

What's inside

It started as a toy. Then the toy kept turning out to be useful.

🏢

A living office

Cubicles grouped by project, private offices from level 5, a kitchen, gym, game room, lounge and meeting room. Agents take breaks, gossip about real events, make friends and celebrate each other's wins.

👀

Status at a glance

Live status from Claude Code: who's busy (and on what), who needs a permission, who's waiting for your reply, and how full everyone's context window is.

👔

A Product Manager

Morgan knows what every agent is doing. Ask "what's blocked?" or let them plan your day. Their suggestions become board cards in one click.

📋

A shared TODO board

To do / In progress / Done. Hand cards to agents, hire someone for them, and watch cards move on their own. Agents can read and add to the board too.

🧍

Daily standup

One key sends everyone to the meeting room and writes a summary of the day, what needs your attention, and yesterday / today / blockers per agent.

🔧

Roles & agents that hire

PR Reviewer, QA Tester, Bug Hunter, Security Auditor, Docs Reviewer, and a Fixer that works on its own git branch. Senior agents can hire helpers themselves.

🤝

Handoffs

Drag one agent's report onto another: "Bug Hunter found this, Dwight fix it". It opens with the report as the first task.

⏱️

Replay the day

Scrub through the last 24 hours and watch who was working when, rebuilt from the transcripts.

🎭

Personalities that matter

Grizzled Senior, Noir Detective, the Dunder Mifflin crew… They change how agents behave in the office and, optionally, how they work in Claude Code.

Quick start

You need Node 18+ and Claude Code. There's nothing to install: no dependencies and no build step.

# your own sessions
git clone https://github.com/alminisl/agent-office && cd agent-office && npm start
# then open http://localhost:4747 and press ? for the tour

# or try the made-up demo office
npm run demo

How it works

  • Reads what Claude Code already writes: transcripts in ~/.claude/projects and live status in ~/.claude/sessions.
  • One small Node server plus a canvas front end. Every sprite is drawn in code.
  • Optional office tools (an MCP server) let your sessions read the board, see the office and hire coworkers.

Privacy

  • Runs on 127.0.0.1 only. Your transcripts never leave your machine through Agent Office.
  • Asking an agent never touches the real session: answers come from a briefing or a forked copy.
  • Background agents get fixed, minimal tools. Fixers work on their own branch and never push.
